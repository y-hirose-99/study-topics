### 2. 【新規】VS Code 拡張の「Fix with Claude Code」と「Resolve Merge Conflicts」— 16 点（条件付き）

- **概要**: Claude Code VS Code 拡張の 2.1.330（2026-11-20）と 2.1.331（2026-11-23）で、エディタ上の情報を右クリックで Claude に渡せるようになった。
  - エラーや警告のクイックフィックス、失敗したテストから「Fix with Claude Code」
  - コンフリクトのあるファイルで「Resolve Merge Conflicts」
  - Source Control の変更ファイルを右クリックして「Add to Chat」
  - 2.1.331 で diff の保存の挙動が変わった。提案された diff は、右側をクリックするか入力した後に保存しないと accept されない。
- **15 分構成案**:
  1. （3 分）エディタから Claude に渡せるようになったもの（診断・失敗テスト・コンフリクト・変更ファイル）
  2. （8 分）デモ 2 本: 失敗するテストを「Fix with Claude Code」で直す → マージコンフリクトを「Resolve Merge Conflicts」で解く
  3. （4 分）diff 保存の挙動変更と、関連する設定（2.1.330 の `escapeStopsClaude` など）
- **想定対象者**: VS Code で Claude Code 拡張を使う人（Web が中心。Android Studio / Xcode の利用者には効かない）
- **条件・注意点（critic 指摘）**:
  - **Copilot との比較表は作らない**（過去テーマ「乗り換え比較」と重なる）。Copilot にも以前から同じような機能がある（推測）ので、質疑で比較の話になる可能性がある。
  - デモは Flutter 以外の小さなリポジトリ（例: TypeScript）で行う。Dart の診断でもこのメニューが出るかは推測なので、言う前に発表者が 1 回試す。
  - コンフリクト解消は毎回出力が変わるので、リハーサルをする。
- **根拠 URL**:
  - https://code.claude.com/docs/en/changelog （2.1.330 / 2.1.331。critic が原文と一致することを確認済み）
